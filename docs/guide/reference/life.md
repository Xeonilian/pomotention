# 生活记录使用方法

::: tip
生活记录用来顺手记下 **喝水、吃饭、活动、睡觉**。日视图写明细；周 / 月 / 年打开图层看趋势。数据挂在当天对应任务上，登录后随任务一起云同步。
:::

- **日视图**：点顶栏生活按钮，任务追踪区域换成四宫格录入面板。再点一次关闭，回到普通任务追踪。
- **周 / 月 / 年**：点顶栏宫格开关图层。开着时，计划表里的普通时间块会让位给生活图层。
- 从周 / 月 / 年点某天的 **日期数字**：打开该日的表视图预览（只看 / 改这一天）。电脑上 **双击** 日期、手机上 **连点两下** 日期，会进入该日的日视图。

## 四类记录

界面上的「活动」是出门办事、如厕一类的时间段，图标是门，不是活动清单里的 Activity。

| 类     | 图标 | 记什么                                                                                          |
| ------ | ---- | ----------------------------------------------------------------------------------------------- |
| 喝水   | 💧   | 每一口的时间和毫升。点水滴图标按当前杯量加一口（默认水）；图上点啤酒杯 / 外带杯 / 咖啡杯 / 酒杯改成饮品、水、咖啡、酒。当日目标可在图上改。 |
| 吃饭   | 🍚   | 时间、类型（正餐 / 甜点 / 水果 / 补剂）、吃了什么。点苹果图标加一条；点披萨 / 蛋糕 / 苹果 / 药箱在四种类型间切换。 |
| 活动   | 🚪   | 开始、结束、去干嘛。点门开始一段；未结束时点停止按钮记下结束时间。                              |
| 睡觉   | 😴   | 入睡、醒来、梦什么。点月亮开始一段；未醒时点停止记下醒来时间。点云朵写梦。                      |

喝水默认杯量 **250 ml**（可改 50–1000），默认日目标 **2000 ml**。改杯量只影响之后新加的一口，已经记下的量不会跟着变。

## 日视图录入

打开后是 **2×2**：喝水、吃饭、活动、睡觉。每一格都有 **图** 和 **表** 两种看法，点格内切换。

### 图

- 点该类的大图标加一条（喝水 = 加一口；吃饭 = 加一餐；活动 / 睡觉 = 开一段）。
- 只编辑 **最后一条**：时间、类型、备注、结束。更早的条目请切到表。
- 没有记录时，吃饭不会露出第二行编辑区。
- 活动 / 睡觉若上一段还没结束，再点大图标会问「上次结束了吗？」
- 睡觉可以跨午夜：昨晚没醒的一段，会继续出现在今天。

### 表

- 列出当天该类全部记录，可改时间、量、类型、备注。
- 表头加号增行，行内删除。
- 活动 / 睡觉表里可以点表头时钟，把开始或结束填成当前时间。

## 周月年可视化

打开图层后：

- **周**：每天一列。喝水是水位波浪；吃饭、活动是散落的标记；睡觉是夜间色带和月亮。电脑上悬停看备注，手机上点标记看。
- **月**：每天四根竖条，从左到右是喝水、吃饭、活动、睡觉。喝水按 **2 L** 一杯的高度画（超过就加杯）；活动条默认按 **2 小时** 满格，当天更长时按向下取整的小时数放大。睡觉条下的时刻是**当天最长那一觉的入睡点**（跨夜只写入睡那天；夜班白天睡也写在入睡那天）。没有记录的格子不画条。
- **年**：当天有任一类生活记录，日期会着色。

图层开着时，时间表上的普通块会隐藏，改显示这些生活标记。关掉图层即恢复。

## 手机预览

在周 / 月 / 年打开生活图层时：

- 时间表和任务追踪区域会先藏起来，方便看计划表；**不会改你平时的显示设置**，关掉图层后还原。
- 顶栏里用来显示 / 隐藏这两块的按钮会跟着变成「当前看不见」的样子。再点它们：先退出预览，再打开对应区域。
- 打开生活录入面板或可视化时，右下角 FAB 会隐藏，避免挡住输入。
- 弹出键盘编辑时，页面会把当前输入滚到中上段，并尽量让该类的大图标仍在屏幕里。

## 限制与说明

- 生活记录 **不是** 活动清单里的待办 / 预约，也不会出现在标签管理器里。系统会为每天四类各准备一条任务行，记录写在这些行上。
- 系统标签（喝水 / 吃饭 / 活动 / 睡觉）不参与年视图事项圆点取色，也不进 [标签系统](tag.md) 的管理面板。
- 云同步走任务字段，登录后与其它任务一起上传下载。本地备份 JSON 里同样在对应 `task` 上。
- 本软件不是医疗或营养日记：没有配餐库、没有睡眠分期，目标是在计划表旁边留下身体节律的痕迹。
