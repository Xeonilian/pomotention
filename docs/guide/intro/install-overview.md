# 安装方式总览

::: tip

- 看流程图选方式，从表格找入口。
- 不登录时 PWA 与网页数据不互通；多设备一致需登录同步。
- 桌面端支持置顶。
  :::

## 怎么选

1. **电脑（Windows / macOS）**
   - 要置顶、本机导入导出 → [桌面客户端](./desktop-install.md)
   - 更在意刷新即更新 → 看下一步（同手机：浏览器能否「添加到桌面」）
2. **手机 / 平板**（或电脑上不想装安装包）
   - 浏览器支持「安装 / 添加到主屏幕」→ [PWA](./pwa-install.md)
   - 否则 → 直接用 [网页](https://pomotention.com)

## 入口

| 方式       | 适合                                            | 链接                             |
| ---------- | ----------------------------------------------- | -------------------------------- |
| 桌面客户端 | 独立应用、置顶计时、数据导入导出                | [安装说明](./desktop-install.md) |
| PWA        | 类App、更新及时，支持数据导入导出，需浏览器支持 | [安装说明](./pwa-install.md)     |
| 网页       | 浏览器打开，不安装、直接使用                    | [链接](https://pomotention.com)  |

## 数据与同步

- **本地**：PWA、网页、桌面端各自先把数据存在本机。
- **登录后**：同一账号下，三端通过云端同步。
- **不登录**：数据不自动同步；PWA与网页、桌面数据**互不相通**。

::: warning

- 不登录：数据只在本地，不自动同步；PWA 与网页数据分开。
- 多设备：各端登录同一账号。
- 数据导出：各端均可 **全量 JSON 导出**（桌面选文件夹；PWA/网页为下载或分享），详见 [账号与数据](./account-and-data.md)。

:::

## 名词

- **PWA**：安装到系统的类 App 用法（主屏/独立窗口/常可离线缓存）。
- **网页**：浏览器直接打开，不安装。
- **桌面客户端**：本机安装程序（Windows/macOS）。
- **同步**：登录后云端与多端一致。
