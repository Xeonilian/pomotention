# 支持与订阅

本机功能（番茄、计划、任务、账本等）**免费**。需要付费的是 **云同步**：登录后多设备同步。

付款走 [爱发电 · xeonilian](https://afdian.com/a/xeonilian)。

## 价目

| 档位 | 金额 | 软件里得到什么 |
| ---- | ---- | -------------- |
| 试用 | 免费 | 登录起 14 天云同步 |
| 订阅 | 9 元/月 或 99 元/年 | 付费期内云同步 |
| 老用户首月半价 | 4.5 元/月 或 49 元/年 | 上线后第一个月内，注册早于上线日的老用户 |
| 打赏 | 默认 9 元 | **不解锁同步**，只是支持开发 |

到期不续：同步停，本机数据仍在，云上已有的可下载带走。

## 试用与到期

- 登录成功起 14 天云同步免费。
- 第 14 天提醒到期，需订购才能继续同步。
- 14 天内也能提前订购，到期日从付款那天起算，不把免费的日子再收一遍。

## 退款

付款后 7 天内不想留，退款，不问原因。付了同步仍打不开也退。退款后同步停，本机照常。

## 站外付款时怎么对上账号

爱发电账号和软件账号不是同一个。**推荐**：打开软件 → 登录 → 顶栏点「订购云同步」。这样订单带上你的账号，开通更快。

从帮助 / 小红书 / 爱发电主页直接付：付款留言填 **软件登录邮箱**。

## 打赏

打赏默认 9 元，感谢支持。它不解锁同步。每月按爱发电收到的打赏排出 top3，寄手绘卡片。

## 还在做、不包含

- 一句记（说话记待办）：以后单独计价，不在云同步这个价里。
- 付款后立刻自动开通（目前到账后 24 小时内人工开通）。
