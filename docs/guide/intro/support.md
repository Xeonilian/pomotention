# 支持与订阅

核心功能（番茄、计划、任务、账本等）**免费**。需要付费的是登录后的 **一句记**（自然语言记进待办）。

付款走 [爱发电 · xeonilian](https://afdian.com/a/xeonilian)。

## 价目

| 档位 | 金额 | 软件里得到什么 |
| ---- | ---- | -------------- |
| 试用 | 免费 | 登录且验证邮箱后，每月 20 次一句记 |
| 订阅 | 19 元/月（年付用爱发电打折） | 一句记高上限（每月 2000 次，防滥用） |
| 打赏 | 默认 9 元 | **不解锁额度**。每月赞助金额 top3 会收到手绘卡片 |

额度用尽时，软件里的升级按钮只指向 **订阅**，避免误点打赏却以为开通了。

## 现在买到什么

- 登录后使用 **一句记**：说一句自然语言，写入当日待办（当前只支持「新建待办」）。
- 试用 20 次/月；订阅后当月高上限。
- 到账后 **当日/24 小时内** 人工开通（自动开通还在做）。

建议：先在软件里登录，再点「订阅」。这样订单会带上账号，开通更快。

## 还在做、不包含

订阅是支持持续开发，不是买断未上线功能。目前 **不包含**：

- 一句记改/删已有记录、更多记录种类
- 付款后立刻自动开通（下一刀）
- 旧版侧边栏 AI 闲聊

## 站外付款时怎么对上账号

爱发电账号和软件账号不是同一个。你 **不用抄一串 ID**。

1. **推荐：** 打开软件或网页 → 登录 → 设置里点「订阅 19 元/月」。
2. **从帮助 / 小红书 / 爱发电主页去的：** 付款留言填 **软件登录邮箱**。开通可能需要数小时；对不上时请用同一邮箱再登录软件，或发邮件说明。

未注册也可以先付钱，之后用 **留言里的同一邮箱** 注册并登录，再联系开通。

## 打赏

打赏默认 9 元，感谢支持。它不会增加一句记次数。每月按爱发电收到的打赏排出 top3，寄手绘卡片。
