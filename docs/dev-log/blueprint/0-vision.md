## 一句话记进 App（与外部 AI 分开）

两件不同的事，不要混成一条开发关：

| | 用户得到什么 | 说明 |
|--|--------------|------|
| **听懂并记上** | 打字/说话一句 → 写成 App 里已有各类记录；错了去原界面改 | **当前选型**；蓝图 [`7-capture.md`](./7-capture.md)；可先打字后语音 |
| **外部 AI 能改 App** | 连上的 AI 直接增改计划/记录，建议落成下一步 | 另一块能力；后置 |

个人 **语音记事**（对着手机说进 App）≠ 下面「一起做感」里的语音房。

## AI：带走摘要 · 外部可控 · 写回卡片

Pomotention 不做聊天主场，而是给用户的 **主力 AI**（Kimi / Claude / Cursor 等）喂上下文、提供工具、在 App 内展示写回结果。

| 旧代号 | 人话 | 含义 | MCP |
|--------|------|------|:---:|
| **A** | 带走摘要 | 结构化摘要导出，你粘贴到外部 AI 聊天 | 否 |
| **C** | 外部 AI 能改 App | AI 用工具读写 Pomotention（增改条目等） | 是 |
| **B** | 写回卡片 | App 内展示 AI 写回（非聊天框） | 依赖 C |

**带走摘要（草案）**

- 周复盘上下文包（估时偏差、番茄节律、打断、精力/奖赏…）
- Activity 级上下文包
- 与 chart 改版共用 **指标定义**（怎么从记录算）

**外部 AI 能改 App（草案）**

- 读：`get_week_summary`、`export_activity_context` 等
- 写：`save_insight_card`、`create_planner_item` 等；规则可控
- 与「听懂并记上」汇合在 **写入本地记录**；AI 已选好工具时不必再走一遍人话解析

**写回卡片（草案）**

- Insight 卡片 UI；非实时 IM
- 可选触发节奏（每日一条、N 个番茄后一条）

侧边栏 AI 对话（v0.4.2）已实现但 **默认关闭**，不在主方向。

## 数据层数据库迁移

localStorage 已偏紧；chart 与「带走摘要」依赖 **稳定可聚合** 的本地读模型。

- **IndexedDB 迁移** — 大改造；与 Supabase 同步衔接单独设计；**不挡**「一句话记上」
- **指标定义** — chart 与带走摘要共用，避免各算各的
- **chart / 数据趋势页** — 展示仍不满意，等指标定义后再改一版

关系：**记录进库 → 按统一规则算指标 → 图表与摘要都吃这套。**

## 记账 / ledger

Pomotention 提取title内容形成单独记账系统，实现消费收入追溯。

**边界：** 不做余额、报表、多账套。

**可能步骤（顺序未钉死）：**

- 文本 → ledger 行识别— 已有本地能力；亦可被「一句话」写入
- Todo 内 code block / 专用模板（可第二版）
- 解析结果或导出历史随 IndexedDB 一并考虑

书写基础已有：`useTaskRecordShortcuts`、`StateLogModal`、`recordedAt` 等（见 CHANGELOG 0.6.x）。
