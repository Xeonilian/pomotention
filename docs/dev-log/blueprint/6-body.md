## 1. 目标与边界（L0）

### 做什么

交互便捷、可视化轻松的身体管理工具；数据可同步；覆盖五方面的记录与展示：

**饮水 · 睡眠 · 运动 · 进食 · 排便**

### 不做什么（整产品层 · 首关禁止）

| 不做 | 说明 |
|------|------|
| 五类平推开发 | 串行按关；壳共用，实现按支线 |
| 万能一张 body 表 | 不为「零冗余」卡死开工；各类各自列表 |
| IndexedDB 当饮水前置 | 全实体 data 层另开总关 |
| 首关瓶子动画 / 日目标 | 属饮水关 3（局部上色），不是关 1 |
| 抢在「一句话总入口」前做录入页 | 见 §0；当前主线在 current |

### 共用骨架意向（壳级 · 非万能表）

各类将来 **各自** 本地列表；仅约定都有：`id` / `loggedAt` / `deleted` / `lastModified` / `synced`。关 1 **不**合并存储。

### 未开关 · 字段意向（半页内）

| 支线 | 字段意向（未定稿） |
|------|-------------------|
| **睡眠** | 上床 / 起床 / 入睡 / 醒来；中途醒来次数与总长；梦；醒来精力；其他。需跨天 |

## 5. 关 1 定稿（饮水 · 本地可记）

> **状态：** 字段定稿保留；**手工 UI 编码后置于「一句话总入口」**（见 §0）。若总入口先写入饮水，改错仍可回到本列表形态。

### 5.1 数据 `HydrationEntry`

localStorage 键名意向：`hydrationEntries`。

| 字段 | 说明 |
|------|------|
| `id` | timestamp 风格 id（对齐 ledger `timestamp_id` 习惯） |
| `loggedAt` | 记录时刻 ms；默认 now，可改 |
| `amountMl` | 正数 ml，自由输入 |
| `beverage` | `'water' \| 'tea' \| 'coffee' \| 'other'` |
| `deleted` | 软删 |
| `lastModified` | 同步/本地变更时间 |
| `synced` | 与现有实体习惯一致；关 1 恒本地（可不上传） |

### 5.2 UI（后置）

- Body 壳：tabs 五格，**仅「水」可用**；其余 disabled 或「未开放」。
- 水页：今日列表（时间 / 类型 / ml）+ **今日合计 ml**；行内改删；末行/按钮追加。
- 录入：时间（默认 now）、类型简选、ml 数字。
- **不做：** 日目标 2000、自定义杯、水滴瓶子、趋势图、云同步。

### 5.3 分层落点（编码时）

| 层 | 落点 |
|----|------|
| UI | `src/components/Body/`（壳 + 饮水页） |
| 数据 | store 扩或薄 store + `localStorageService` load/save（仿 ledger 进 `useDataStore`） |
| 入口 | [`HomeView.vue`](../../src/views/HomeView.vue) |
| 分层 | 遵守 [`1-architecture-layering.md`](./1-architecture-layering.md) |

### 5.4 关 1 验收（开手工 UI 关时用）

1. Home 一点进入 Body 壳，默认水页  
2. 可追加一条：时间可改、类型四选一、ml  
3. 今日列表可见；合计正确  
4. 可改、可软删  
5. 刷新后 localStorage 仍在
