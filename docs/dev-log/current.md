## 验收标准（5 条）

1. 一句记入口可打字（系统 IME 语音填同一框即可，不做自研 STT）  
2. LLM 能把典型记账句映射成 intent 并写入 ledger  
3. Gift/明细可见；可在原界面改删  
4. 映射不上（schema 不过 / confidence 低 / target 锁不住）→ 不写，有提示  
5. 付费门闩先 stub：未付费提示升级，不提供规则替代；正式额度与价目留待收费关
